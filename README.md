# Basic Poll App 
This project will be a basic poll web application, that will contain 5 different flaws from the [OWASP top ten list (2021)](https://top10.owasp.org/2021/) and their fixes.

This is the course project for [Introduction to Cyber Security](https://cybersecuritybase.mooc.fi/) [part VII](https://cybersecuritybase.mooc.fi/module-3.1).
